# PixelBoard Advanced releases

Public home for PixelBoard Advanced's release APKs. The app's in-app updater checks the
[latest release](https://github.com/animeshahilya/pixelboard-advanced-releases/releases/latest)
here, so new versions can be found and downloaded without signing in.

- Each GitHub Release here (tagged `v<version>`, e.g. `v1.0.0-beta.1`) carries that version's
  `PixelBoardAdvanced-<version>.apk` and its notes.

PixelBoard Advanced is built on [PixelBoard](https://github.com/Akshayykadam/PixelBoard) by
Akshay Kadam and stock Gboard. It needs an arm64 phone on Android 10 or later, and installs next
to Gboard and PixelBoard.
